Icons

The model pane

  1. Frosted pane. Translucent surface with a bright 1px edge, 14px corners. Solid tint when blur is unavailable.
  2. Material colour. The preview is drawn in the colour of the recipe's material: PETG teal, PLA orange, TPU magenta, ASA grey. Unknown material stays neutral.
  3. Name and catalogue number. Number per library, never reused (proposal).
  4. Requirements and last print. Recipe chips (mono only when they hold numbers); status as icon, word and date, never colour alone.
